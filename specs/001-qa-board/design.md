## 1. 디자인 콘셉트와 목표

### 콘셉트
QANOW는 **신뢰감 있고 효율적인** Q&A 플랫폼으로, 회원이 질문하고 관리자가 답변하는 직관적인 흐름을 시각적으로 구현합니다.

### 핵심 목표 (spec.md §Goals 연결)
1. **첫인상 강화** (§Goal 4): 메인 페이지 30초 내 서비스 이해
2. **작업 효율성** (§Goal 3): 관리자가 미답변 질문을 빠르게 찾고 답변
3. **신뢰감 구축** (§Goal 1-2): 명확한 권한 분리와 상태 표시
4. **접근성** (constitution.md §Principle V): 모든 사용자가 쉽게 이용

## 2. 브랜드 이름과 핵심 문구

### 로고
- **마크**: "Q" 문자 + 선형 그라데이션 (#0d47a1 → #7c4dff)
- **크기**: 36px × 36px (모바일), 가로세로 동일
- **테두리 반경**: 6px (완전히 둥글지 않게)
- **배치**: Header 좌측, sticky position

### 브랜드명
- **한글**: "QANOW" (정서체, 20px, 700 weight)
- **색상**: #0d47a1 (어두운 네이비)
- **배치**: 로고 우측 12px 간격

### 핵심 문구
- **Hero 메인**: "질문은 빠르게, 답변은 명확하게."
- **Hero 서브**: "궁금한 점을 남기면 관리자가 확인하고 답변해드립니다."
- **Empty (미답변)**: "아직 답변이 없습니다. 관리자가 곧 답변해드릴 예정입니다. 잠시만 기다려주세요."
- **Empty (질문 목록)**: "아직 질문이 없습니다."

## 10. Aurora Gradient, Grid Glow, Floating Card 효과

### Aurora Gradient (Hero 배경)

```css
background: linear-gradient(135deg, #0d47a1 0%, #5e35b1 50%, #0277bd 100%);
```

- **방향**: 좌상향 → 우하향 (135도)
- **목표**: 부드럽고 세련된 그라데이션 (과도하지 않음)
- **성능**: CSS만 사용 (애니메이션 없음)

### Grid Glow (배경 패턴)

```svg
<pattern id="grid" width="40" height="40">
  <path d="M 40 0 L 0 0 0 40" stroke="white" stroke-width="1"/>
</pattern>
```

- **목표**: 배경에 깊이감 추가, 텍스트 읽기는 방해하지 않음
- **투명도**: opacity 0.08 (매우 약함)
- **패턴 크기**: 40px × 40px
- **성능**: SVG 인라인 (추가 요청 없음)

### Floating Card (우측 예시)

```
Card Structure:
├─ Question Card (white, shadow)
│  ├─ Label: "QUESTION" (주황, 11px, 600 weight)
│  └─ Text: 예시 질문
├─ Arrow: "↓" (rgba(255,255,255,0.4))
└─ Answer Card (white, shadow, left-border 4px green)
   ├─ Label: "ANSWER" (초록, 11px, 600 weight)
   └─ Text: 예시 답변
```

- **위치**: Hero 우측, 50% 수직 중앙 (데스크톱만)
- **너비**: 280px-320px
- **배경**: 흰색 (#ffffff)
- **그림자**: 0 4px 12px rgba(0,0,0,0.15)

## 21. 키보드 포커스와 접근성

### 키보드 네비게이션 (spec.md §524)

```
순서: Tab 키로 논리적 순서 이동

포커스 표시:
  아웃라인: 2px solid #0d47a1 (또는 네이티브)
  오프셋: 2-4px (요소 바깥)
  색상: 명확히 구분 가능 (대비 비율 3:1 이상)

포커스 순서:
  1. Header Nav (로그인/회원가입 또는 로그아웃)
  2. Hero CTA ("지금 질문하기")
  3. 메인 콘텐츠 (리스트/상세)
  4. Footer 링크

포커스 트랩:
  없음 (ESC 키로 모달 닫기 등 미구현)
```

### 스크린 리더 지원 (spec.md §525)

```
ARIA 라이브 리전:
  상태 변경: <div role="status" aria-live="polite">
    - "저장되었습니다" (성공)
    - "오류 발생" (실패)
    - "로딩 중..." (진행)

라벨:
  입력 필드: <label for="id"> (명시적)
  버튼: aria-label 제공 (필요시)

이미지:
  alt 텍스트: 모든 이미지 (또는 aria-hidden="true" decorative)
  Placeholder: 입력창 (label 대체 불가)

Heading:
  구조: H1 (페이지 제목) → H2/H3 (섹션)
  순서: 건너뛰지 않음 (H1 → H2 → H3)
```

### 색상 대비 (WCAG AA)

```
텍스트 대비 비율:
  일반 텍스트 (< 18px): 4.5:1
  큰 텍스트 (≥ 18px): 3:1

검증 색상 조합:
  #0d47a1 (navy) on #ffffff (white) ✓ 7.0:1
  #4b5563 (body gray) on #ffffff ✓ 6.5:1
  #616161 (gray) on #ffffff ✓ 5.5:1
  #4caf50 (green) on #ffffff ✓ 4.0:1
  #ff9800 (orange) on #ffffff ✓ 4.5:1
```

## 22. prefers-reduced-motion 규칙

### CSS 구현 (spec.md §526, design-brief §18)

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }

  .loading-spinner {
    animation: none !important;
    border-top-color: #e5e7eb; /* 회전 불가, 정적 표시 */
  }
}
```

### 적용 범위

| 요소 | 기본 | 모션 감소 시 |
|------|------|----------|
| 로딩 스피너 | rotate 애니메이션 | 정적 (회전 없음) |
| Hero 텍스트 | fade-in (선택) | 즉시 표시 |
| 카드 호버 | 그림자 변경 (transition) | 즉시 변경 |
| 버튼 호버 | 색상 변경 (transition) | 즉시 변경 |
| 페이지 전환 | (미구현) | N/A |

### 사용자 설정 존중

```
감지:
  window.matchMedia("(prefers-reduced-motion: reduce)")
    .matches

Polyfill: 필요시 JavaScript fallback
  (리스트 순환 로딩 등 구현 시)
```

## 23. 금지할 디자인 패턴

### ❌ 피해야 할 패턴 (design-brief §19, constitution §principle V)

1. **과도한 Glassmorphism**
   - 반투명 배경 + 블러 효과 극도로 제한 ❌
   - 읽기 어려움, 성능 저하
   - Hero 배경만 그라데이션 사용

2. **과도한 둥근 모서리**
   - 버튼: 6px 이상 금지 ❌
   - 카드: 8px 이상 금지 ❌
   - 현재: 6px (버튼), 8px (카드) ✓

3. **화려한 애니메이션**
   - 스크롤 시 요소 날아오기 ❌
   - 회전, 점프, 흔들림 ❌
   - 로딩 스피너만 회전 (간단함) ✓
   - 지속시간: 300-500ms max

4. **AI 랜딩 페이지처럼 보이기**
   - 보라색·무지개색 배경 금지 ❌
   - Aurora는 순수 그라데이션 (무지개 아님) ✓
   - "AI가 생성했어요" 표현 금지 ❌
   - 추상 곡선·스펙 요소 남용 금지 ❌

5. **정보 과다**
   - 메인: 서비스 세부 기능 설명 금지 ❌
   - 상세: 불필요한 정보 추가 금지 ❌
   - 현재: 3단계 + 3가지 가치만 ✓

6. **반응형 미고려**
   - 모바일 텍스트 크기 감소 금지 ❌ (현재 유지함)
   - 터치 타겟 44px 미만 금지 ❌
   - 가로 스크롤 필요 금지 ❌

7. **색상만으로 상태 표현**
   - 배지: 색상 + 텍스트 필수 ✓
   - 카드: 좌측 border + 배지 텍스트 ✓

8. **필터/기능 과다**
   - 리스트: 상태 필터만 (검색, 정렬 없음) ✓
   - 향후: 추가 기능은 Phase 2
